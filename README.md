# Healthcare Appointment & Patient Service Management

## Streamlit Web Application

This project provides a browser-based interface for the existing modular Python healthcare appointment system.

### Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

### Modules
- Dashboard
- Patient management
- Doctor management
- Appointment booking/rescheduling/cancellation/completion
- Doctor/date/time conflict detection
- Daily patient queue
- Statistics and doctor workload reports
- CSV persistence
- CSV export
